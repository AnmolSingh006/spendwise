# SpendWise – Personal Expense Tracker 💰

A modern, minimal and responsive personal expense tracker built to help you manage your money, track daily spending and understand your financial habits.

SpendWise provides a simple dashboard to monitor income, expenses, budgets and financial activity — all in one place.

## ✨ Features

- **Financial Dashboard** – Get an overview of your total balance, income and expenses.
- **Income Tracking** – Record and manage your earnings.
- **Expense Tracking** – Track daily purchases and spending.
- **Transaction Management** – Add, edit, delete and search transactions.
- **Category Management** – Organize transactions into categories.
- **Expense Analytics** – Visualize spending patterns using interactive charts.
- **Budget Tracking** – Set monthly budgets and monitor spending limits.
- **Dark Mode** – Switch between light and dark themes.
- **Local Storage** – Save your financial data directly in your browser.
- **Responsive Design** – Optimized for desktops, tablets and mobile devices.
- **CSV Export** – Export transaction records for personal analysis.

## 🚀 Getting Started

Follow these instructions to run SpendWise locally.

### 1. Clone the repository

```bash
git clone https://github.com/AnmolSingh006/spendwise-expense-tracker.git
```

### 2. Navigate to the project directory

```bash
cd spendwise-expense-tracker
```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 💾 Data Storage

SpendWise uses browser LocalStorage to store transactions and user preferences.

- No account registration required.
- No backend or database required.
- Data persists between browser sessions.
- Financial information stays within the browser's local storage.

**Note:** Browser data may be lost if the user clears site data or uninstalls the application. This version does not provide cloud synchronization.

## 📱 Android Application

SpendWise is designed to be extendable into an Android application using Capacitor.

The Android version can package the existing web application into an installable APK without rebuilding the entire application.
